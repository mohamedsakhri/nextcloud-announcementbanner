# Security Policy

## Supported versions

Security fixes are released for the latest version of the app only. Please update to the newest release from the Nextcloud App Store before reporting an issue.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
https://github.com/mohamedsakhri/nextcloud-announcementbanner/security/advisories/new

Please include:

- the app and Nextcloud versions you tested,
- steps to reproduce, including an example request or payload,
- the impact you expect (who can exploit it, and who is affected).

You can expect a first response within 7 days. Once the issue is confirmed, a fixed release is published and the reporter is credited in the changelog and the security advisory, unless they prefer to stay anonymous.
